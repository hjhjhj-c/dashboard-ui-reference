# 차트

기준 파일: `src/components/chart-area-interactive.tsx` (기간 선택 영역 차트)

## 핵심 패턴 — ChartConfig

모든 차트는 이 구조를 따릅니다:

```tsx
const chartConfig = {
  desktop: { label: "웹", color: "var(--chart-1)" },
  mobile: { label: "모바일 앱", color: "var(--chart-2)" },
} satisfies ChartConfig

<ChartContainer config={chartConfig} className="h-60 w-full aspect-auto">
  <AreaChart data={data}>
    <Area dataKey="desktop" stroke="var(--color-desktop)" fill="var(--color-desktop)" fillOpacity={0.15} isAnimationActive={false} />
  </AreaChart>
</ChartContainer>
```

- `label`만 바꾸면 범례·툴팁에 자동 반영됩니다. 시리즈 키(`desktop`)는 데이터 키와 일치해야 해요.
- 색은 `var(--chart-1)`~`var(--chart-5)` 또는 `var(--primary)`. hex 금지 — 다크 모드 자동 대응이 깨집니다.
- 차트 안에서 그 색을 참조할 때는 `var(--color-시리즈키)` (ChartContainer가 만들어 주는 변수).

## 다른 차트 종류 추가

shadcn 공식 차트 갤러리(https://ui.shadcn.com/charts)에서 원하는 형태를 찾아
`npx shadcn@latest add <차트이름>` 하거나 코드를 복사하세요.
전부 Recharts 기반이라 `ChartContainer` 패턴이 동일합니다.
막대(Bar)·라인(Line)·파이(Pie)·레이더까지 같은 방식이에요.

## 라벨 잘림 방지

- X축에는 `tickMargin`·`minTickGap`을 유지하세요. 현재 메인 차트는 각각 `12`·`24`를 사용하고, 선택 구간에서 다섯 날짜를 눈금 후보로 잡아요.
- 날짜 포맷은 `toLocaleDateString("ko-KR", { month: "short", day: "numeric" })` → "6월 24일".
- 차트 높이는 `className="h-60 w-full aspect-auto"`처럼 ChartContainer에 지정합니다.
  부모 카드에 고정 높이를 또 주지 마세요.
- 값이 큰 숫자면 Y축에 `tickFormatter={(v) => v.toLocaleString("ko-KR")}`.

## 데이터 연결

메인 차트의 원본은 `trafficData`예요. 각 행은 `date`(`"2024-06-30"` 형식),
`desktop`, `mobile` 값을 가져요. 현재 `filteredData`는 `slice(-Number(timeRange))`로
마지막 7·30·90개 행을 선택해요. 날짜가 오름차순이고 하루에 한 행씩 있어야
행 수가 조회 일수와 같아져요. 기준은 오늘이 아니라 데이터의 마지막 행이에요.

API를 연결할 때는 응답을 정렬하고, 날짜 누락·중복 처리 기준을 정하세요.
빈 응답이나 로딩 중에는 차트의 시작·마지막 날짜를 읽지 않도록 로딩/빈 상태를 먼저 처리해야 해요.
현재 표시하는 2024년 및 6월 30일 기준 문구(`App.tsx`, `chart-area-interactive.tsx`,
`insight-rail.tsx`)도 실제 응답 기간에 맞춰 바꾸세요.

개요의 소스 도넛·KPI와 그래프 예시 화면은 각각 별도 목업을 사용해요.
메인 차트 배열만 교체해도 다른 화면의 수치가 자동으로 연결되지는 않아요.
