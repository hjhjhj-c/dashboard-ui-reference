# 구조와 규칙

## 레이어 3단

1. **`src/components/ui/`** — shadcn 프리미티브. 버튼·카드·셀렉트 같은 부품입니다.
   여기 코드는 `npx shadcn@latest add <이름>` CLI가 관리한다고 생각하세요.
   직접 수정하면 나중에 같은 컴포넌트를 다시 add할 때 덮어써질 수 있습니다.
   스타일을 바꾸고 싶으면 (1) `index.css`의 CSS 변수, (2) 사용하는 쪽에서 `className` 추가 —
   이 두 가지로 해결이 안 될 때만 ui/ 파일을 수정합니다.
2. **`src/components/`** — 조립 컴포넌트. KPI 카드 묶음, 차트 카드, 데이터 테이블처럼
   "화면의 한 구역"이 한 파일입니다. 주 작업 공간이에요.
3. **`src/App.tsx`** — 페이지. 조립 컴포넌트를 배치합니다.

## 새 화면을 만드는 순서

1. 부품 라이브러리(`#reference`)와 `src/components/reference/`에서 필요한 부품을 먼저 찾아요.
2. 기존 조립 컴포넌트(`section-cards.tsx` 등)에 비슷한 구성이 있으면 복사해 변형해요.
3. 없으면 shadcn 부품이나 완성 화면(https://ui.shadcn.com/blocks)을 확인하고,
   `npx shadcn@latest add <이름>`으로 추가한 뒤 한국어화·데이터 교체를 진행해요.
4. 필요한 부품이 갖춰지면 ui/ 프리미티브와 함께 화면을 조립해요.

## 자주 하는 실수 Top 5

1. **팔레트 색 직접 지정** — `bg-white` `text-gray-600`은 다크 모드에서 깨집니다.
   → `bg-card` `text-muted-foreground` 같은 시맨틱 클래스.
2. **TanStack Table v8 예제 복붙** — 웹의 예제 대부분이 v8입니다. 이 프로젝트는 v9라서
   `useReactTable`이 아니라 `useTable` + `tableFeatures()` 등록 방식이에요.
   `data-table.tsx`를 기준으로 삼으세요.
3. **Recharts를 직접 스타일링** — `ChartContainer`/`ChartConfig`를 거치지 않으면
   툴팁·범례·다크 모드 색이 전부 어긋납니다.
4. **`TooltipProvider` 제거** — `App.tsx`의 Provider 순서를 바꾸거나 지우면
   사이드바 툴팁에서 앱 전체가 죽습니다.
5. **고정 높이에 텍스트 욱여넣기** — `h-24` 같은 고정 높이 + 여러 줄 한글 = 글씨 잘림.
   높이는 내용이 정하게 두고, 길이 제한이 필요하면 `line-clamp-*` + `title` 속성.

## 화면을 늘릴 때

현재는 `App.tsx`에서 URL 해시와 탭 상태를 연결해 일곱 화면을 전환해요.
`src/lib/dashboard-navigation.ts`의 `dashboardViews`가 화면 ID·라벨·제목·설명을 정의하고,
`app-sidebar.tsx`의 `mainItems`와 `resourceItems`가 사이드바 메뉴를 구성해요.

화면을 추가할 때는 `dashboardViews`에 항목을 넣고, `App.tsx`에 같은 ID의
`TabsContent`를 추가하세요. 상단 탭은 `dashboardViews`에서 자동으로 만들어져요.
사이드바에도 보이게 하려면 `mainItems` 또는 `resourceItems`에 ID와 아이콘을 추가하세요.
해당 화면은 `#화면ID` 주소로 바로 열 수 있어요.

경로 기반 라우팅이 필요해지면 그때 라우터 도입과 배포 서버의 SPA 폴백을 함께 검토하세요.


## Astra 화면 구성

- `App.tsx`에서 개요·그래프 예시·데이터셋·운영 품질·상세 페이지·모달 예시·부품 라이브러리를 전환해요.
- 사이드바와 상단 탭은 같은 상태를 사용하고, `#overview`, `#charts`, `#datasets`, `#quality`, `#detail`, `#modals`, `#reference` 주소로 바로 열 수 있어요.
- 개요와 데이터셋은 하나의 `DataTable` 인스턴스를 공유해요. 다른 탭을 방문해도 행 선택·순서·페이지 상태가 유지돼요. 새로고침하면 샘플 초기 상태로 돌아와요.
- 메인 차트의 7·30·90일 선택은 2024년 6월 30일을 포함한 정확한 일수를 보여줘요. 우측 소스 도넛은 명시된 6월 30일간 합계예요.
- `chart-examples.tsx`의 네 그래프는 각각 독립적인 목업이에요. 개요 수치와 합산하지 않아요.
- 상단의 **샘플 CSV**는 원본 `data.json`을 내려받아요. 화면 편집 결과의 저장이나 서버 연동 기능은 아니에요.
- `#detail`은 `detail-data.ts`를 사용하는 독립적인 이미지 상세 예시예요. 표에서 여는 상세 드로어와 별개이며, 관심 표시와 내부 탭은 화면을 나가면 초기화돼요. 상세 화면의 CSV는 물류 예시 3행이에요.
- `#modals`의 입력·완료 예시는 `ExampleDialog`, 삭제 확인은 Radix `AlertDialog`를 사용해요. 화면 상태만 바꾸며 서버에 저장하지 않아요. 사용법은 [모달과 상세 페이지](./05-모달과-상세페이지.md)를 참고하세요.


## 색상 테마 선택

- 헤더의 색상 테마 메뉴에서 **블루·바이올렛·틸·로즈·앰버**를 선택해요. 기본값은 블루예요.
- 색상과 라이트/다크 모드는 별도 설정이에요. 색상을 선택한 뒤 밝기를 전환해도 같은 팔레트가 유지돼요.
- 선택값은 `dashboard-color-theme` 키로 localStorage에 저장하고, `<html data-color-theme="violet">`처럼 적용해요. 첫 화면을 그리기 전에 저장된 색상을 읽어서 새로고침 때의 색상 깜빡임을 막아요.
- 팔레트 값은 `src/index.css`의 `:root[data-color-theme="..."]`와 `:root.dark[data-color-theme="..."]`에서 관리해요. 블루는 기본 `:root` / `.dark` 값을 사용해요.
- 강조색·버튼·포커스 테두리·사이드바 강조와 차트 1~3번 계열이 함께 바뀌어요. 차트 4~5번은 중립색을 유지하고, **성공·주의·실패 상태색은 모든 팔레트에서 같아요.** 배경과 본문 색, 메시 그라디언트도 별도로 유지해요.
- `--brand-hover`는 강조색에 본문 색을 8% 섞어서 버튼의 호버 대비를 유지해요. `--ring`, `--sidebar-primary`, `--sidebar-ring`, `--chart-1`은 `--brand`를 참조해요. 새 팔레트에서도 컴포넌트에 색을 직접 쓰지 않고 기존 시맨틱 클래스를 사용하세요.
- 선택 메뉴의 색상 견본은 `bg-theme-blue`·`bg-theme-violet`·`bg-theme-teal`·`bg-theme-rose`·`bg-theme-amber`를 사용해요. 이 견본 토큰은 현재 선택한 색상과 독립적이며, 라이트/다크 모드의 실제 강조색을 보여줘요.
- 새 팔레트를 추가하거나 수정할 때는 두 모드의 작은 강조 글씨, 선택된 메뉴, 버튼 기본/호버 상태를 확인하세요. 현재 팔레트는 카드 및 10% 강조 배경 위 글씨와 `hover:bg-brand-hover` 버튼 호버까지 최소 4.5:1 대비를 확보했어요.
